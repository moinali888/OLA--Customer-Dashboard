# OLA- Customer-Dashboard
- PowerBI Dashboard
- Project Overview
  This dashboard has been created to visualize the ride data of OLA customers. In this, customers' surge price impact, payment mode, driver rating, customer rating, and ride satisfaction are analyzed.

2️⃣ Features & Objectives
✔ Interactive customer analytics dashboard
✔ Data filtering by date, City etc.
✔ Insights on customer payment mode & price.
✔ Dynamic visualizations using graphs & charts
✔ Performance monitoring (e.g., average customer rating, drive rating)
